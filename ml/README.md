# Machine Learning / AI Directory

This directory contains assets and resources related to machine learning and AI modeling within this project.

Structure
---------

- `data/` – Raw datasets and intermediate processed data.
- `notebooks/` – Jupyter or Zeppelin notebooks for exploratory analysis and prototyping.
- `models/` – Serialized model artifacts (e.g., `.pkl`, `.pt`, `.onnx`).
- `experiments/` – Experiment configurations, logs, and results.
- `scripts/` – Python (or other language) scripts for training, evaluation, and utilities.

Keep large data files out of Git or use Git-LFS where appropriate.
